# Layout ledger

One row per published investigation. The picker reads the Layout column to
count uses; everything else is for you.

**Verdict** is yours to fill in, any time: `keep`, `drop`, or a word about what
worked. A row with an empty verdict just hasn't been judged yet.

After about a month, run `/research layouts` — it reports uses per layout,
which ones are under-represented, and what you've written here.
