# Hardware

What the machine actually does under the abstraction.

| Area | Holds | Go-to sources |
|---|---|---|
| `microarchitecture` | Pipelines, branch prediction, out-of-order execution, side channels | ISCA, MICRO, Agner Fog, Intel/Arm docs |
| `memory-storage` | Cache hierarchy, DRAM, flash, NVMe, CXL | JEDEC, FAST, CXL Consortium |
| `accelerators` | GPUs, TPUs, NPUs, interconnects, memory bandwidth limits | Hot Chips, ISCA, IEEE Micro |
| `interconnects` | PCIe, networking silicon, RDMA | PCI-SIG, NSDI, IEEE |
| `embedded` | Microcontrollers, real-time constraints, power | IEEE, vendor reference manuals |
| `fabrication` | Process nodes, packaging, yield, cost | ISSCC, VLSI Symposium, IEEE |
