# Biology

Mechanisms and evidence. Every health claim names study design and size inline,
and a systematic review beats any single study.

| `molecular-cell` | Proteins, metabolism, signaling, cell biology | Cell, Nature, NCBI Bookshelf |
| `genetics-genomics` | Inheritance, gene regulation, sequencing, CRISPR | Nature Genetics, Ensembl, eLife |
| `neuroscience` | Neurons, circuits, sleep, learning, memory | Nature Neuroscience, Neuron, Annual Reviews |
| `physiology-health` | Exercise, nutrition, endocrinology, aging | Cochrane, BMJ, NEJM, PubMed |
| `evolution-ecology` | Selection, speciation, ecosystems, microbiome | PNAS, Science, PLOS |
| `immunology` | Innate and adaptive immunity, vaccines | Nature Reviews Immunology, Lancet |
